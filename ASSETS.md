# Asset sources

All profile names, ages, locations, colleges, biographies, and interests are fictional mock data. Photographs are stand-ins and do not identify the fictional profiles.

- First demo portrait: Unsplash image source, https://images.unsplash.com/photo-1534528741775-53994a69daeb. Use is subject to the Unsplash License, https://unsplash.com/license. This image is a placeholder for Aanya and does not represent that person's identity.
- Other demo portraits: Random User Generator placeholder images, https://randomuser.me/api/portraits/. Individual source paths match filenames, such as `men-32.jpg` from `/men/32.jpg`. See https://randomuser.me for the source service. These are the original small placeholder images and can look soft at full card size.
- DM Sans and Manrope: Google Fonts, https://fonts.google.com/specimen/DM+Sans and https://fonts.google.com/specimen/Manrope. SIL Open Font License 1.1. License texts are included in `public/fonts/`.
- Interface icons: Lucide React, ISC license, https://lucide.dev/license. The package's license is included by npm.
- Favicon and fallback silhouette: original simple SVG artwork for this demo.

Local copies avoid third-party portrait/font requests while the app is used. Replace placeholder portraits with licensed, user-provided images in a real product.
